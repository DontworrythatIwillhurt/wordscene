# 词间 Wordscene

直接双击 `dist/index.html` 即可离线阅读与练习。英语发音使用设备语音服务；部分系统语音可能需要联网。

## 当前内容

- 300 篇原创中英对应短篇：112 篇修仙、188 篇悬疑，保留原来的 40 篇并新增 260 篇。
- 6,131 个参考词表词条，33 个补充词汇，总计 6,164 词。
- 6,164 / 6,164 个内置词均有实际故事语境，覆盖率 100%，遗漏 0。
- 307 个参考词表学习单元，每单元最多 20 词；可从每个词回到对应故事。

**全覆盖指当前内置词库：每个词至少在一篇故事的英文情节中出现并标注。** 统计不将词汇列表、中文释义或未标注的字符串碰巧出现算作故事覆盖，不代表穷尽每个词义、所有出版词表或之后自添的词。词表来源、许可与范围见 `dist/SOURCES.md`。

## 学习功能

故事阅读采用两步：第一步在中文网文情节中读粗体英文和本句释义；第二步把同一段剧情中的词换成编号输入框，回填英文原形。可以关闭首字母提示，提交后查看逐空反馈、只重练错词，或重新填整篇。查看参考答案不计入词汇掌握；中途切换阅读/填空或查看词卡保留本轮输入。刷新会结束当前填空草稿，已提交的学习记录仍保留。

中文正文按人物行动、对白和冲突重写，避免使用不解释的黑话。现有故事编号、英语例句、词库及收藏仍沿用原数据；英文原文可在第一步下方展开。中文句子的标记为 `[[word-id|本句语境义]]`，阅读与填空直接从同一份文本生成。

手机页面采用底部导航、横向主题筛选、竖向词库卡片和底部释义弹层。按钮按触屏操作加大，支持窄屏、横屏、专注与夜间阅读。手机样式和增强逻辑位于 `dist/mobile.css`、`dist/mobile.js`，沿用同一份内容与学习记录。

已在独立浏览器测试环境中检查 320、360、375、390、414、430、768、1024 像素宽度，以及 844×390 横屏；验证词库检索、笔记保存、中英对照、夜间与专注阅读、整章测验、学习日历和单元阅读。未在实体手机上测试系统键盘或语音。

中文故事中的英文与释义 → 同剧情挖空回填；可展开英文原文。另有中文选词、拼写、听音拼写；间隔复习、错词与收藏专练；全文及单词朗读；字号、语速、夜间模式、专注阅读；阅读书签、联想笔记、学习日历；自定义词汇；JSON 进度导出/合并恢复及收藏 CSV 导出。

章节测验包含本章全部重点词。日常自由练习仍以 12 词为一轮。词汇弹窗可查看所有对应故事，短词留空不会误删其他单词内部的字母。

进度沿用原来的 `wordscene-v2` 存储格式，原故事编号、词汇编号、笔记与书签保持兼容。旧版 `wordscene-v1` 词汇进度仍会迁移。移动文件、改用在线网址或换浏览器前请导出备份。

## 内容维护与校验

发布文件在 `dist/`，可以直接上传到 GitHub Pages，无需在服务器安装依赖。

手机兼容版把页面脚本合并成 `wordscene.compat.js`，转换较新的 JavaScript 语法（目标 ES2017 / Chrome 60），移除初始化中的 `matchAll`、`flatMap` 和正则后行断言，补充 `Object.fromEntries` 和旧内核的对话框支持。`startup.js` 会在脚本无法加载或启动失败时显示重试与诊断信息，避免只剩导航的空白页面；构建时自动更新脚本版本，减少旧缓存干扰。

已验证新版浏览器，以及模拟缺少新接口和原生 dialog 的环境：书架、307 个单元、整章测验、词卡与笔记持久化均通过。尚未在用户的 vivo 浏览器和微信内置浏览器中完成实体测试；浏览器禁用 JavaScript 或网络拦截仍会阻止内容加载。

修改页面脚本后，使用 Node.js 安装构建依赖并重新生成兼容文件：

```sh
npm install
npm run build
```

网页依旧沿用 `wordscene-v2` 学习记录。更新时上传 `dist/` 中的文件，不上传整个源码目录。

```sh
node merge-stories.mjs     # 合并三组新增故事，未完整覆盖将报错
node merge-cloze.mjs       # 合并三组网文改稿，逐篇校验全部词各标记一次
node verify-data.mjs      # 逐词、真实标记、例句、旧编号及完整覆盖校验
npm run build             # 更新手机兼容版脚本及版本号
node serve.mjs            # 可选本机预览
```

`dist/story-coverage.json` 保存完整的单词到故事映射及覆盖检查结果。原始扩展故事在 `content-work/stories-{1,2,3}.json`，网页使用合并后的 `dist/expanded-stories.js`。

网文中文改稿在 `content-work/cloze/output-{1,2,3}.json`，合并结果是 `dist/cloze-stories.js`；交互与样式在 `dist/cloze.js` 和 `dist/cloze.css`。构建后的网页只请求合并的 `wordscene.compat.js`，其中已包含所有数据与交互，上传时必须与当前 `index.html` 一起更新。

填空会忽略大小写及首尾空格，并接受已列明的常见英美拼写变体。原参考词表中的 `reservior` 保留原条目编号用于旧进度兼容，但故事明确标注其误拼，填空按标准 `reservoir` 判分。

修改前的原版本备份保存在项目旁的 `wordscene-backups/before-full-coverage` 目录。
